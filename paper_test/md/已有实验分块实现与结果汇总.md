# 已有实验分块、实现方式与结果汇总

> 更新：2026-11-16。本报告聚焦已经存在的实验，不将前面讨论的新方案作为现有成果。依据本地源码、保存的评价摘要和训练日志整理；部分神经元指标由已有预测与已有裁判记录重新统计，没有重新训练、运行模型或调用外部裁判。模型身份若仅由目录命名推断，保留原始目录标识；结果不能脱离数据版本和评价规则直接比较。

## 1. 可以分为哪几块

建议归为七块主要实验，加一块扩展验证。它们覆盖数据、领域能力、输出可信度、内部检测和外部证据。


| 编号 | 实验块 | 解决的问题 | 现状 |

|---|---|---|---|

| A | 区域新闻与 QA 数据集 | 有哪些新闻、能构造哪些问题、数据质量怎样 | 有数据、划分、增强与质量抽样记录 |

| B | 领域适配与通用能力保留 | 模型能否掌握区域新闻；领域训练是否损伤通用能力 | 有 CPT／MOL-CPT／SFT、领域评价与 MMLU |

| C | 生成概率与知识边界判别 | 已有答案能否通过置信信号识别对错 | 有阈值消融、神经网络判别器和测试日志 |

| D | 模型内拒答学习与置信一致性 | 能否通过训练直接改变回答／拒答行为 | 有多版 SFT／DPO／分类头／COKE，部分结果退化 |

| E | 语义熵不确定性 | 多次回答的语义分歧是否能识别不可靠答案 | 有采样、聚类、SE／DSE 及门槛搜索；完整独立评价待补 |

| F | CETT／H-Neurons 检测 | 内部神经元贡献是否能识别幻觉 | 有多种训练器、内部报告及问题级预测；两种评价差距明显 |

| G | RAG 与生成策略 | 外部新闻能否改善回答，剩余错误来自哪里 | 有大量时序、切块、门控、模型和提示对照及错误归因 |

| H | 跨模型与原型扩展 | 是否能扩展到其他模型、通用问答、多跳或 Agentic | Qwen3 有训练产物；Agentic 有异常；TriviaQA 部分标签无效 |



最清晰的关联是：A 提供数据，B 提升领域回答能力；C、D、E、F 是不同可信度路线；G 利用外部证据；H 是扩展。它们不代表全部已经联合接入一套最终系统。

## 2. 结果阅读规则

本文区分四种数值：

1. **领域回答正确率**：闭卷答案在既有裁判规则下被判正确的比例。
2. **决策准确率**：把正确答案保留、把错误答案拒绝的分类准确率，包含正确拒答，不是总体正确回答率。
3. **已回答正确率**：保留／实际回答的问题中正确的比例。
4. **总体正确回答率**：正确且被保留的答案占全部问题的比例，不把拒答计为正确答案。

阈值文件中的 performance 通常是搜索所用数据上的表现，不能自动称为独立测试成绩。H-Neurons 的训练内结果以特征行为样本，问题级复核以回答为样本。RAG 大部分摘要 accuracy_rate 以非拒答数量为分母。

对 RAG，本文同时列出 N（总数）、R（拒答数）、C（正确数），并从摘要重算：覆盖率=(N-R)/N，已回答正确率=C/(N-R)，总体正确回答率=C/N。摘要一致性不能替代逐条人工真值核验。

## A. 区域新闻与问答数据集

## B. 领域适配、微调与通用能力保留

### B1. 实现方式

- 标准 CPT：新闻 CSV 转文本／JSONL，采用语言模型目标继续训练。
- MOL-CPT：领域新闻与通用指令交替输入，学生学习领域文本，同时匹配教师在通用数据上的输出分布。cpt_unsloth.py 当前 General 批次损失为 alpha*CE+(1-alpha)*KL，Domain 批次为 (1-alpha)*CE+alpha*KL；main 中 alpha=0，所以分别为通用 KL 与领域 CE。
- 新闻 SFT／QLoRA：用问答数据训练模型按问题回答；混合 SFT 另加入 Magpie 通用指令。
- 评价：domain_test 生成领域回答并调用裁判；MMLU 对通用多选知识进行评价。

源码当前配置不一定等于历史产物配置。比如一年新闻 finetune.py 当前是 rank=128、dropout=0.15、lr=2e-4、3 epochs；finetune_2dataset.py 当前是 rank=128、dropout=0.1、5 epochs。不要直接用这组配置解释所有历史 checkpoint。

## C. 置信度指标与知识边界判别

### C1. 实现方式

对同一个问题生成原始答案，收集 PPL、最小 token 概率和模型自报置信度。以既有裁判的 score 构造标签，搜索单指标、双指标与三指标阈值；一般规则为低 PPL、高最小概率、高自报置信度时保留答案。

贝叶斯搜索使用 Optuna，以 Youden J 等目标选择阈值。另一个分支将 3 项指标扩展成 13 维，再训练 MLP、Attention 和 Ensemble；决策树版本扩成 9 维，实际跳过 score==3，而非照注释把它算作正类。

## D. 拒答 SFT／DPO、分类头与 COKE

### D1. 实现方式

这一块直接训练语言模型或附加头，区别于 C 中主要对已生成答案做后验分流。

| 方向 | 实现 | 关键入口 |
|---|---|---|
| 生成式拒答 SFT | 可回答样本给正常答案，错误／不足样本给拒答或反思模板 | refusal_dpo/code/sft.py、嵌套 test/train.py |
| SFT+DPO | 构建 chosen/rejected 对，在 SFT 后优化回答偏好 | code/dpo.py、test/test1/code/dpo.py、new_test/code/dpo.py |
| 生成+拒答分类头 | 语言模型损失与二分类损失联合训练 | sft_class.py |
| refusal-only | 侧重训练拒答分类头，保存 refusal_head.pt | sft_class_1.py |
| margin 排序 | 正负序列对数似然的 margin 损失 | refusal_sft.py |
| 模板与比例 | 两类／四类模板、反思、10:1 SFT 与 1:1 DPO | code/test、new_test |
| COKE | direct/prior/posterior 三种条件下的置信一致性与语言模型 CE | coke/code/train.py |

COKE 当前 total_loss=ce_loss+CONSISTENCY_WEIGHT*consistency_loss，置信度采用目标 token 几何平均概率；不能仅据程序变量含 dpo/ppo 就将其等同于 TRL 的 DPO/PPO 训练。

## E. 语义熵与离散语义熵

### E1. 实现方式

对每个问题采样 10 个回答 → 用本地 LLM 判断两回答语义等价 → 按语义聚类 → 汇总簇概率 → 计算语义熵；DSE 则按各簇样本频率计算熵。门槛低于某值时保留答案，高于时标记风险。

## G. RAG、检索策略、生成与错误归因

### G1. 实现方式

主要入口：demo_system.py 为门控版本；demo_system_nodecide.py 为不经过直接回答门控的纯 RAG；demo_tiqu.py 先抽证据再生成；demo_xuanze.py 生成多个候选后选择。Agentic 另列 H。部分文件含多个实际入口，当前源码不能自动解释所有历史输出。

### H2. Agentic RAG

实现了查询分析、改写、HyDE、查询分解、迭代检索和答案验证。已有 data/test/test.json 保存 1,403 条结果；按现有 JSON 检查，1,143 条 verification 含验证异常或 Invalid json output，1,304 条 confidence=0，只有 96 条内部 verification.is_supported=True。

这 96 条不是独立正确数，内部自检也不是人工真值；未见完整独立评价。当前属于已运行但验证链路不稳定的原型，不能作为成熟方法的有效成绩。诊断附件：[paper_test/analysis/Agentic输出完整性检查.json](../../paper_test/analysis/Agentic%E8%BE%93%E5%87%BA%E5%AE%8C%E6%95%B4%E6%80%A7%E6%A3%80%E6%9F%A5.json)。

### H3. TriviaQA／Llama-2 知识未知性

unknow_test 使用 Llama-2-7b-chat 生成答案、PPL、最小概率与自报置信度，再按答案和别名匹配评价。

- train_evaluate 有 61,888 条，其中 correctness.correct=True 为 36,537 条，匹配正确率约 59.04%；这是保存训练分割上的已有回答评价。
- test_evaluate 有 7,701 条，ground_truth.value 全为 <unk>，aliases 全为空，correct 全为 False。该评价的真值缺失，0% 不能解释为模型失败，应在有答案的划分上重评或补齐真值。

### H4. 多跳与早期学习实验

multihop_qa 实现 Neo4j 实体关系抽取、二跳／三跳路径、关联新闻补充；当前 QA 生成入口只处理前 3 条，属于样例原型。

Qwen2.5-1.5B-lora、DeepSeek QLoRA 主要是医疗 QA，llama_grpo 主要是 GSM8K 格式与正确性奖励实验；CONQORD 是置信校准参考框架。这些有方法积累价值，但本次不把它们的损失或结果直接并入区域新闻论文性能表。

## 3. 目前可以稳妥提炼的实验认识

1. 已建立完整的数据到模型、评价和 RAG 的实验资产，且有自动 QA 质量抽样记录。
2. 新闻 SFT 在既有领域测试上带来明显收益，但通用 MMLU 降低，领域与通用能力存在取舍。
3. 自报置信度单独作用弱；PPL 与最小 token 概率组合有价值，但必须以验证集选阈值、测试集报告结果。
4. 拒答 SFT／DPO 和附加分类头并非稳定有效，现存负结果与过度拒答同样值得报告。
5. 语义熵已完成计算和门槛探索，尚需核验独立正确性标签与测试链。
6. 神经元训练内结果较高，问题级现存预测明显下降，不能以内部特征行分数替代最终问答收益。
7. RAG 在当前结果中是提升区域新闻问答的主要有效路线；门控不总是优于纯 RAG，切块、时间条件、模型与提示均需隔离归因。
8. 剩余错误有相当部分被工具判断为已召回相关证据，说明生成与证据使用值得重点研究，但召回归因口径需对齐。
9. Qwen3 可作为跨模型扩展资产，Agentic 和 TriviaQA 测试当前存在完整性问题。
