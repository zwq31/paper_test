# 实验3
对于dpo，所以对于模型回答正确的问题，应该chosen应该是chosen输出是正确答案+高置信度，rejected输出可以是拒绝回答+高置信度或者正确答案+低置信度，对于模型回答错误的问题，chosen输出是错误答案+低置信度或者拒答+低置信度，rejected输出可以是错误答案+高置信度吗，那sft就是对于模型回答正确的问题输出是正确答案+高置信度，对于模型回答错误的问题拒答+低置信度
sft：正确回答样本输出为正确答案+高置信度  错误回答样本输出为拒答+低置信度
